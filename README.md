## 🎯 Learning Outcomes

Through these practical assignments, the repository demonstrates:

- Understanding of Java fundamentals and OOP concepts.
- Developing graphical user interfaces using AWT and Swing.
- Implementing multithreading in Java applications.
- Understanding client-server architecture and socket communication.
- Working with Java Remote Method Invocation (RMI).
- Creating and using JavaBeans.
- Performing file handling and CSV-based data storage.
- Implementing CRUD operations for student record management.
